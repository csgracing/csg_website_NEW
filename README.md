# csg_website_NEW

New CSG Racing Website for the 2026/2027 season (IN PROGRESS)

## Tech stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript + React
- [Tailwind CSS](https://tailwindcss.com)
- [Framer Motion](https://motion.dev) for animation
- Local JSON files for content/data (no database)
- Deployed on [Vercel](https://vercel.com) (connected once the site is ready to launch)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
